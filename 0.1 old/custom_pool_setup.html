🎯 2. 目标高稀有度 (出金) 设定

勾选在数据统计中被视为“出金 / 重置保底”的稀有度层级。

🎁 3. 多重副产物保底 (低金/低星保底)

你可以自由设置多个保底规则 (如: 每10抽保底紫，每5抽保底蓝)。
注：已被设为「目标金」的层级不可选，请在下方单独设置金保底。

📈 4. 保底与动态概率 (分段软保底)

可以设置多个区间。例如：63-73抽每次增加7%，74-80抽每次增加3.5%。

🛡️ 5. 大保底 (命定值) 设定

在未命中 UP (歪了) 累计 次后，下一次金必定出 UP。
(注：填1即标准的歪一次后必中；填2即原神武器池神铸定轨)

✨ 6. 歪出挽救机制 (原神“捕获明光”/二次保底逆转)

当出金掷骰判定为“歪常驻”时，不会直接发常驻，而是进行二次掷骰挽救；若连歪达到阈值，则强制救回为当期 UP。
标准原神设定：基础挽救率填 10%（实现综合 55% 不歪率），防连歪硬保底填 1。

🎁 7. 「井」与抽数里程碑保底设定

支持传统兑换井（如 300 抽换真限定），也支持特定抽数里程碑防非保底（如绝区零 50 抽前未出金必出、方舟联动 120 抽前未出必送）。

✨ 8. 前 N 金胜率特权序列 (独家重映 / 首出金福利)

可添加多行按序生效的胜率福利。例如：第 1 金不歪率 100%，第 2 金不歪率 100%（即首两金必出 UP）。
注：特权次数用完后，将自动无缝回退至卡池基础 UP 概率；若期间触发大保底必中，大保底优先结算，特权顺延！

🎁 9. 前 N 金类型定向序列 (新手首金必出角色/轮替福利)

可指定卡池前几金命中时，必须从哪些「图鉴积木」中出货。例如：第 1 金指定从【常驻角色】出货，第 2 金从【常驻武器】出货。
注：超出设定的金数后，自动恢复卡池全局随机。
