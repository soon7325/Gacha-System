# 中英文翻译

## 内容与范围
- 翻译前先读取用户刚修改后的源文件，不凭旧聊天内容重建文案。
- 默认以用户定稿的中文为来源，保持意思、编号和信息量一致；英文自然表达，不逐字生硬翻译。
- 不擅自添加承诺、解释、功能或用户已删除的内容。
- 用户只要求某个文件或词条时，限定修改范围；要求中英文同步时检查双方一致。
- 新功能同时提供中英文文案；已有文案的翻译以用户指定范围为准。
- 版本日志翻译同时遵守 [changelog.md](changelog.md)。

## 词条与代码
- 复用已有合适词条，不重复创建含义相同的 key。
- 中英文新增词条使用相同 key，放在相应位置，沿用现有排序和格式。
- 保留 `{name}` 等占位符、HTML 标签、链接与程序依赖属性，避免翻译破坏功能。
- 不把人名、邮箱、版本号、文件路径和代码标识符当作普通文字翻译。
- 明确区分日志模板字符串中的实际换行、UI 文案中的转义换行以及 HTML `<br>`，按具体文件用途处理。
- 完成后检查语法、遗漏词条和对应关系；不要借翻译任务批量改写无关历史文案。
