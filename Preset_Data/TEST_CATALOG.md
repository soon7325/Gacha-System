# 测试专用数据库

文件：`Preset_Data/db_test.js`。游戏编号：`test`；中文名“测试专用”，英文名“Feature Test Lab”。在 `db_zzz.js` 后加载，复用现有绝区零205项代理人、音擎、邦布和本地图片；数据深拷贝，不修改绝区零预设，也不与其账户共享余额、持有或记录。所有数字用于功能测试，不代表实际游戏规则。

## 显示开关

测试库主标志和21个卡池均使用独立AI生成的透明PNG徽记，保存在 `img/TEST/icon/`。暖金主体搭配青绿点缀，以盾牌、时钟、节点等符号区分测试场景；生成提示词见同目录 `generation-prompts.json`。图鉴素材仍复用绝区零。

设置 → 启动与导航 → 显示“测试专用”图鉴。`GM_Show_Test_Catalog` 默认关闭。

关闭时，侧栏、卡池入口和默认启动页选项均隐藏测试数据；直接访问或浏览器返回测试页面会回到首页。若默认启动页曾指向测试内容，自动回退首页。已保存的测试账户、记录和规则保留，再次开启仍可使用。不同版本继续使用原有存储隔离。

## 卡池场景

大部分卡池S级12抽硬保底、A级4抽小保底；启用软保底的卡池在第8～11抽递增概率。基础稀有度概率与候选装配参考本项目绝区零预设，门槛缩短以便操作。

| 卡池编号 | 覆盖内容 |
| --- | --- |
| char_up | 经典大保底、A级UP与小保底、软保底、本期目标切换 |
| wep_up | 前两金UP特权、歪两次后的保证 |
| char_up_2 | 递进保底，每次歪提升25个百分点，最高100% |
| wep_up_2 | 救援，随机触发25%，连续歪两次强制救援，命中后清零 |
| rescue_decay | 救援，命中UP后歪数递减 |
| rescue_retain | 救援，命中后保留值上限 |
| rescue_keep | 救援，命中后保持歪数 |
| mixed_std | 前两金分别指定角色/音擎；6抽可取消新手井；15抽自选额外井；20抽循环额外井；分类权重倍数 |
| spec_std | 特殊候选绝对概率65%，与分类权重倍数场景分开 |
| bangboo_up | 邦布必定UP、独立支付票券及副产物 |
| gift_up | 5抽一次性赠送2抽（计保底）；每10抽赠送1抽（不计保底）；15抽循环替换井；换期继承与重置 |
| prereq_chain_up | 3抽井 → 解锁首金胜率 → 解锁类型定向 → 解锁赠送抽，赠送最多2次 |
| prereq_combo_up | 抽数与规则触发次数组合：全部满足、任一满足；来源井最多2次 |
| catchup_all_up | 完成10抽后解锁，保留进度并补发全部；每3抽井／赠送，最多2次 |
| catchup_one_up | 同上，仅补发一次 |
| catchup_none_up | 同上，跳过过去里程碑，后续继续正常累计 |
| sequence_skip_up | 2抽硬保底；10抽后解锁第1金福利，序号已过则跳过 |
| sequence_next_up | 同上，将错过的第1金胜率及定向福利顺延到下一次可用自然金 |
| expiry_after_unlock_up | 先用首金特权获得UP，6抽后解锁循环奖励；只检查解锁后获得的目标 |
| expiry_including_before_up | 相同设置，但检查解锁前已经记录的UP，因此解锁时即可失效 |
| expiry_rule_up | 来源井成功触发后，停止后续赠送；验证失效条件与触发次数上限并存 |

非标准卡池均可开启新一期；继承垫抽、大保底、救援，重置前金特权、分类定向、井与赠送规则。规则配置页可查看详细矩阵。

以上前置规则在完成条件后的下一抽检查解锁；从零计数不包含完成条件的那一抽。保留进度的补发在解锁后首次可结算的普通抽执行。赠送抽计入总抽数，但不会自行再执行井／赠送奖励判断；赠送抽是否推进保底与自然金序列由“计保底”决定。所有测试规则都有固定 ID 和中英文名称，前置引用使用 ID。井／赠送进度保持旧索引结构，同时保存所属规则 ID，读取和执行前会按 ID 对齐，避免改名、排序或删除后串进度。

## 货币与资源

初始余额为零。进入模拟器启用货币模式后，在“获取／兑换”里选择“测试补给：资源名”，显式领取资源，不自动写入玩家账户。

- 保留绝区零原有资源、支付及返还；补充测试十连券和测试代币。
- 补给不限次数：母带、邦布券、测试十连券每次10；其他资源每次20,000。
- 支付覆盖单抽、整组十连、卡池适用范围和余额不足时组合补足。
- 获取覆盖一次性、每日、每月、不限次、三日签到。
- 返还覆盖每次、首次、首次与重复（不含溢出）、重复（含溢出）、重复不含溢出、仅溢出、满阶分段；包含标签任一/全部和不同图鉴大类、稀有度及卡池筛选。多条命中时叠加。
- 满阶总件数：代理人3、音擎2、邦布2，便于快速复现溢出。测试首次/重复时关闭“低星目标自动填溢出”并使用空白持有；测试溢出时可开启该选项或手填已有数量。

## 兑换场景

1. **共享第二层**：第一层母带240×2＋菲林40×6＝720；再扣770测试代币解锁。第二层“母带”和“菲林”两个项目同时开放，解锁费只收一次，兑换各自付款；月重置后需重新完成前置和解锁。
2. **永久组**：先完成一次性阶梯，再消耗5测试代币及10菲林；解锁后可兑换一次性十连券。月重置保留解锁。
3. **月度阶梯**：10代币换1母带（两种择一）；20换2邦布券；30换1测试十连券。逐档进行，月重置恢复。
4. **一次性阶梯**：5代币换1母带；10换1测试十连券，月重置不恢复。
5. **纯文本前置**：手动确认文字条件，只支付每次兑换费，不额外收解锁费。
6. **普通兑换**：固定不限次、多目标每次择一、每种目标分别限购，保留绝区零原有示例。

## 建议检查顺序

1. 开启测试图鉴，打开“赠送抽／循环替换井”，执行十连，查看免费抽标签及赠送计数。
2. 进入货币模式，领取测试代币补给，完成第一层两项并支付770，检查第二层两项目一起开放、重复点击不重复扣费。
3. 完成永久组与月度组，月重置，检查永久组保留、月度组重新锁定、余额不清空。
4. 在玩家数据页建立多个测试账户，填写不同垫抽、井与持有；检查账号切换、默认账号、录入同步、保存与临时使用。
5. 关闭测试图鉴，检查侧栏和启动选项消失，已打开的测试页面返回首页；再次开启，确认测试账户仍存在。

自动检查覆盖全部卡池抽取、物品素材存在性、检测器一致性、货币配置引用、解锁结算、默认隐藏、关闭后重定向与保留账户。
