不仅仅是记录，更是你的专属「抽卡沙盒」

打破传统抽卡工具只能绑定单一游戏的限制。在这里，你可以像拼积木一样，从零构建任何游戏的抽卡引擎。

🌟 核心特性

🛠️ 终极自定义引擎

完全解绑图鉴。支持自定义星级颜色、分段式软保底曲线、动态增幅、命定值（大保底）与多重「井」机制。你的规则，你说了算。

📊 硬核数据剖析

告别玄学测算。实时为你统计「不歪率」、「平均出金抽数」以及精准的垫池进度。欧非守恒定律，用数据一眼看透。

🎲 沉浸式跃迁模拟

完美复刻底层概率逻辑的模拟器。支持拖拽指定「自选 UP 神坛」与「特限概率干预」，抽卡前先来这里测测风水。

☁️ 本地+云端双轨运行

默认开启本地运算，保障极致丝滑的响应速度；绑定账号后无缝接入 Firebase 云端，多设备自动融合，数据永不丢失。

🎮 你可以用它做什么？

  • 作为资源规划管家： 同时管理《星穹铁道》、《绝区零》、《明日方舟》等多款游戏的保底进度。
  • 作为抽卡整活器： 新建一个“群友池”或“生活池”，把朋友的头像录入图鉴，模拟抽出他们的概率。
  • 作为概率验证机： 输入官方公布的概率曲线，利用百连抽甚至千连抽模拟器验证实际期望值。
  • 作为小型游戏开发者： 输入自己为自己游戏填充的概率，并在测试后实时修改规则。

☁️ 以【云端】为主相互融合
