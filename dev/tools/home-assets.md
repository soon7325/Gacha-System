# 首页图片

背景放在 `img/OTHER/index/`，图标放在 `img/<游戏前缀>/icon/game_icon.webp`。

- `ZZZ 01 both.jpg`：中英文共用的常驻背景。
- `ZZZ 02 en.png`、`ZZZ 02 zh.jpg`：同一张常驻背景的英文版和中文版。
- `ZZZ NEW 01 en.webp`、`ZZZ NEW 01 zh.png`：同一张最新进度背景的英文版和中文版。
- `ZZZ NEW 02 both.jpg`：中英文共用的最新进度背景。NEW 可以添加多张并继续编号。
- 文件名末尾的 `en`、`zh`、`both` 决定语言；英文仅使用 `en + both`，中文仅使用 `zh + both`。未标记语言的旧文件按 `both` 兼容。
- 支持 JPG、PNG、WebP、AVIF；前缀不区分大小写，分隔可用空格、下划线或短横线。
- 更新进度时请移除旧的 NEW 图，或改为数字常驻命名。

添加或删除图片后，在项目目录运行：

```sh
node dev/tools/build-home-assets.cjs
```

将生成的 `pages/home-assets.js` 与图片一起部署。静态网站无法直接读取服务器目录，因此通过清单提供图片列表，不依赖目录浏览功能。

首次展示、自动随机、「下一张」和图片计数均只使用当前语言的候选。切换语言时保留当前游戏和看板目标；正在展示语言专属图片时优先切到同编号的对应语言版本，共用图保持原位。无对应语言或共用图时显示暂无可用背景，不使用另一种语言的图片。

新前缀会自动成为新的展示游戏；已注册的游戏沿用 `ui/layout.js` 的名称与翻译，未注册的先显示前缀。游戏导航窗口始终最多三个图标，上下箭头循环选择其他游戏。首次随机选择一个游戏并优先展示其 NEW 图片，此后每分钟仅在当前游戏内随机切换另一张背景，不改变游戏名称、选中图标或看板链接。游戏仅通过左侧图标和上下箭头手动切换，选择游戏时同样优先 NEW。图片预加载成功后才开始虚化交叉切换；失效图片会跳过。

暂停旁的「下一张」按文件名顺序循环展示当前游戏的背景，包含常驻与 NEW 图片。切换成功后重新开始一分钟计时；已暂停时仍可手动换图，并保持暂停。加载期间或没有其他可用背景时禁用此按钮。

首页展示不受四款游戏的图鉴显示开关影响；点击「查看游戏看板」时实时检查开关。未开启时保留在首页，并以中英文 Toast 提示前往设置开启。测试图鉴仍遵循单独的显示开关。
